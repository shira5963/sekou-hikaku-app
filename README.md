# 施工前&施工後 比較報告書 作成アプリ

## セットアップ手順

### 1. Pythonのインストール
まだの場合は https://www.python.org/ から Python 3.10以降をインストールしてください。

### 2. 必要ライブラリのインストール
このフォルダ（project）で以下を実行します。

```
pip install -r requirements.txt
```

### 3. 日本語フォントの準備（重要）
PDF生成に使う fpdf2 は、標準のままでは日本語（施工前・施工後・物件名など）を表示できません。
以下の手順でフォントを用意してください。

1. `project/fonts` フォルダを作成する
2. 「IPAexゴシック」フォントをダウンロードする（無料・商用利用可）
   - 配布元: https://moji.or.jp/ipafont/ipaex00401/
3. ダウンロードしたファイルの中の `ipaexg.ttf` を `project/fonts/ipaexg.ttf` として配置する

配置後のフォルダ構成:
```
project/
├─ app.py
├─ pdf_builder.py
├─ docx_builder.py
├─ requirements.txt
├─ fonts/
│   └─ ipaexg.ttf   ← ここに配置
├─ assets/
│   └─ logo.png     ← 表紙に載せる会社ロゴ(同梱済み)
└─ ...
```

### 4. アプリの起動

```
streamlit run app.py
```

ブラウザが自動で開き、アプリ画面が表示されます。

## 使い方

1. **STEP 1** 物件名を入力する（例：◯◯レジデンス101号室）
2. **STEP 2** 表紙の設定
   - 表紙中央に写真を入れる場合は「表紙あり」を選び、写真をアップロード
   - 写真を入れず空白でよい場合は「表紙なし」を選択
   - 必要であれば担当者名を入力（空欄でも可）
3. **STEP 3** 「施工前の写真」「施工後の写真」をそれぞれまとめてアップロードする
   - **同じ場所の写真は、施工前・施工後で同じファイル名（先頭の連番）にしておいてください**
     例）`01_リビング.jpg`（施工前）と `01_リビング.jpg`（施工後）
   - ファイル名の順番で自動的にペアリングされます
4. **STEP 4** 表示されるペア一覧を確認する（ズレていたらファイル名を直して再アップロード）
5. **STEP 5** 「PDFで作成」または「Wordで作成」ボタンを押し、生成されたファイルをダウンロードする

出来上がる報告書は、1ページ目が表紙（物件名・写真報告書・写真・ロゴ・会社情報）、2ページ目以降が施工前後の比較写真になります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | Streamlitの画面（入力・アップロード・確認・生成ボタン） |
| `pdf_builder.py` | 表紙＋A4比較レイアウトでPDFを組み立てる処理 |
| `docx_builder.py` | 表紙＋A4比較レイアウトでWordを組み立てる処理 |
| `requirements.txt` | 必要なPythonライブラリ一覧 |
| `fonts/ipaexg.ttf` | 日本語表示用フォント（別途ダウンロードして配置） |
| `assets/logo.png` | 表紙下部に配置する会社ロゴ |

会社名・住所・電話番号などの固定情報を変更したい場合は、`pdf_builder.py` と `docx_builder.py` の先頭付近にある `COMPANY_NAME` などの定数を書き換えてください。
