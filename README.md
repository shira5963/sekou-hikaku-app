# 施工前&施工後 比較報告書 作成アプリ

## セットアップ手順

### 1. Pythonのインストール
まだの場合は https://www.python.org/ から Python 3.10以降をインストールしてください。

### 2. 必要ライブラリのインストール
このフォルダ（project）で以下を実行します。

```
pip install -r requirements.txt
```

### 3. 日本語フォントの準備（重要）
PDF生成に使う fpdf2 は、標準のままでは日本語（施工前・施工後・物件名など）を表示できません。
以下の手順でフォントを用意してください。

1. `project/fonts` フォルダを作成する
2. 「IPAexゴシック」フォントをダウンロードする（無料・商用利用可）
   - 配布元: https://moji.or.jp/ipafont/ipaex00401/
3. ダウンロードしたファイルの中の `ipaexg.ttf` を `project/fonts/ipaexg.ttf` として配置する

配置後のフォルダ構成:
```
project/
├─ app.py
├─ pdf_builder.py
├─ docx_builder.py
├─ requirements.txt
├─ fonts/
│   └─ ipaexg.ttf   ← ここに配置
├─ assets/
│   └─ logo.png     ← 表紙に載せる会社ロゴ(同梱済み)
└─ ...
```

### 4. アプリの起動

```
streamlit run app.py
```

ブラウザが自動で開き、アプリ画面が表示されます。

## 使い方

1. **STEP 1** 物件名を入力する（例：◯◯レジデンス101号室）
2. **STEP 2** 表紙の設定
   - 表紙中央に写真を入れる場合は「表紙あり」を選び、写真をアップロード
   - 写真を入れず空白でよい場合は「表紙なし」を選択
   - 必要であれば担当者名を入力（空欄でも可）
3. **STEP 3** 「施工前の写真」「施工後の写真」をそれぞれまとめてアップロードする
   - **同じ場所の写真は、施工前・施工後で同じファイル名（先頭の連番）にしておいてください**
     例）`01_リビング.jpg`（施工前）と `01_リビング.jpg`（施工後）
   - ファイル名の順番で自動的にペアリングされます
4. **STEP 4** 施工中画像・その他（任意）
   - このページの題目を入力（デフォルト「施工中画像」、変更可）
   - 施工前後の比較に含めない写真（施工中の様子など）をアップロード
   - 1ページに4枚×5段＝最大20枚配置され、超えた分は自動で次ページに続きます
   - 各写真の下にコメントを入力できます（1行に収まる文字数まで）
5. **STEP 5** ペアリング結果の確認・修正
   - ズレている場合は「施工後の写真」のプルダウンで選び直せます
   - ▲▼ボタンでページ内の表示順を入れ替えられます
   - 各写真の下にコメントを入力できます（1行に収まる文字数まで）
6. **STEP 6** 「PDFで作成」または「Wordで作成」ボタンを押し、生成されたファイルをダウンロードする

出来上がる報告書は、1ページ目が表紙、続いて施工前後の比較ページ、最後に施工中画像・その他のページ（アップロードした場合のみ）という構成になります。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `app.py` | Streamlitの画面（入力・アップロード・確認・生成ボタン） |
| `pdf_builder.py` | 表紙＋A4比較レイアウトでPDFを組み立てる処理 |
| `docx_builder.py` | 表紙＋A4比較レイアウトでWordを組み立てる処理 |
| `layout_utils.py` | ページサイズ・記入欄の文字数制限など、共通のレイアウト定数 |
| `requirements.txt` | 必要なPythonライブラリ一覧 |
| `fonts/ipaexg.ttf` | 日本語表示用フォント（別途ダウンロードして配置） |
| `assets/logo.png` | 表紙下部に配置する会社ロゴ |
| `usage_logger.py` | 利用ログ(日時・物件名・担当者名・IPアドレス)を記録する処理 |
| `logs/usage_log.csv` | 記録された利用ログ(初回、報告書作成時に自動で作られます) |

会社名・住所・電話番号などの固定情報を変更したい場合は、`pdf_builder.py` と `docx_builder.py` の先頭付近にある `COMPANY_NAME` などの定数を書き換えてください。

## 利用ログ機能
PDFまたはWordを作成するたびに、以下の情報が `logs/usage_log.csv` に自動で追記されます。

- 日時
- 物件名
- 担当者名
- 作成した形式（PDF／Word）
- アクセス元のIPアドレス

アプリ画面の一番下にある「📋 利用ログを見る（管理者向け）」を開くと、記録済みのログを一覧表示・CSVダウンロードできます。

**注意点：**
- IPアドレスの取得はStreamlitが公式に提供している機能ではなく、内部の仕組みを利用しています。将来Streamlitのバージョンが上がった際に取得できなくなる可能性があり、その場合は自動的に「不明」と記録されます（アプリが止まることはありません）。
- ログは、アプリを動かしているパソコン（サーバー役のパソコン、またはStreamlit Cloud）にファイルとして保存されます。Streamlit Cloud上で使う場合、再デプロイ時にログが消えることがあるため、社内サーバー役のパソコンで運用する場合により確実に記録が残ります。
